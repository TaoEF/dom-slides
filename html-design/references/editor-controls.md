# 编辑器操作参考

可编辑对象目前由 HTML 的 `data-el` 显式标记；浏览器真实 DOM 负责几何和文字排版，尚不自动识别任意未标记内容。

默认单页居中预览并适应窗口，左侧页面栏170px，页脚与缩略图可换页。预览保留内容原有交互；点「编辑」进入普通元素编辑，点「✓ 完成」回到预览。页面管理和 AI 审阅可直接从预览执行，后台安全交接写权限；AI 接管等待与修改阶段暂停写操作。

## 内容与页面

- 拖动移动元素，双击改字或裁切图片，替换图片使用工具条「替换」。文字角点同比缩放字号、内部小字和行距，边点只调整框；图片提供「适应」完整显示与「填充」裁切铺满。可用顶部入口插入文字/图片，也可拖入或粘贴图片。
- 顶部「自动排版 / 手动」只切换当前页；切回自动排版恢复该页快照，原绝对定位 CSS 不会自动变成 Flex。
- 文字「更多 → 文字适配」检测溢出，提供「高度随内容」与「缩小字号适配」（最小6px），均可单步撤销。
- 顶部形状入口可插入八种基础形状。选中后圆形色样分别控制填充、描边；线宽用数字或箭头调整。矩形、三角形、菱形、星形和块箭头有独立圆角控制；星形与箭头的其他几何调整在元素右键菜单。拉伸时线宽与圆角保持设计像素值。
- 预览即可拖动缩略图排序、点「＋」新增，页面「⋯」可复制、重命名、删除、上下移动；缩略图支持 Ctrl/⌘ D、Delete、Alt + ↑/↓。拖动取消不提交排序。
- 翠绿色辅助线提示页面/元素边缘、中心吸附，以及同一行或列中相邻对象的等距居中和间距延续；间距标签按设计像素显示整数，仅显示取整，不改实际几何或 Grid/Flex 的 gap。Alt/Option 暂停吸附，Esc 取消拖动。蓝色选框和控制点表示选择。

选中元素可拖动选框外的旋转手柄；90°附近吸附，Shift为15°步进，Alt/Option自由旋转，Esc取消。单选可在工具条「旋转」输入页面绝对角度或重置0°；多选绕共同中心，显示本次增量。旋转后拖动和缩放仍使用实际局部尺寸，保留已有transform/均匀scale/origin。反射、skew、3D等不可靠几何暂禁用这些操作。

## 组合

至少选择两个同页、同父容器且顺序相邻的对象，在工具条或元素菜单点「组合」，或按 Ctrl/⌘ G；单选组合后可「取消组合」（Ctrl/⌘ Shift G）。单击成员选择整体，双击逐层进入，组内再次双击文字或图片仍可编辑。Esc先结束当前拖动、裁切、菜单或文字输入，再退出一层组合；元素菜单也可进入、返回上层。框选和方向扩选遵守当前组合范围。

组合采用 `div[data-group="1"][data-el]` 与 `display:contents`，实际布局和变换仍由成员的CSS决定，不保存另一套坐标JSON。整体移动、微调、旋转复用多对象操作；仅提供保持比例的角点缩放，成员视觉尺寸和间距同比变化。取消组合仅解开包装，保留成员变换后的当前外观。方向选框、旋转手柄与等比角点缩放共享实际成员角点计算的局部外框，旋转后松手或重选保持方向。组合、取消和每次有效手势各单步Undo；支持嵌套、复制重键、删除与撤销，删空后清理空组合。

普通Grid/Flex保持成员继续参与原布局。组合/取消前同步检查当前页成员、后代、未选兄弟的实际尺寸、文字行、样式和绘制顺序；结构选择器、不连续选择或保存重解析会改变结构时明确拒绝并恢复，取消组合也检查重解析稳定性。链接内部暂不组合，可将整个链接作为成员。该检查针对当前渲染，不保证未来媒体查询、动态CSS或内容脚本改结构后仍兼容。保存和重新打开保留语义组合；PPTX沿DOM祖先保留原生群组和可编辑子对象，PDF使用实际DOM。

组方向用 `data-group-angle-v1` 保存相对真实父坐标轴的角度提示，不改变渲染；缺字段的旧组默认沿父轴，不猜测已有成员角度。嵌套组不叠加外层提示，真实旋转祖先自然影响方向；组内改字/成员变换后重算外框。临时多选只在当前选择集合内保留整体旋转方向，换集合后沿页面轴重新开始，不写入成员DOM，也不开放多选缩放。参考线和QA仍看实际成员可见外框；PDF/PPTX以真实CSS导出，不再次作用方向提示。

## 图片裁切

双击图片或点「裁切」，在框内拖动调整取景，缩放控件放大源图，边点/角点改变裁切窗口。图片始终覆盖窗口；缩小框保留原图尺寸，扩大到需要时才增加覆盖。Enter/完成确认，Esc/取消恢复进入前整个状态。每个有效手势或数值确认可单独撤销；会话内 Undo/Redo 使用局部历史，首次迁移撤销后仍可继续。进入并完成、边界夹住、拖回起点不会产生新结构或历史。

有效操作才把原图片变为 `span[data-crop-frame="1"][data-el] > img[data-crop-image]`。外框承担布局、变换、边框和圆角；原 img 节点保留 id/class/src/alt/链接，其原布局 CSS 值转到外框，内部 CSS 承担真实取景。保留百分比宽度、auto 自然高度与 Grid/Flex item 属性；不以固定 px 替代百分比。内部 `--crop-zoom`、`--crop-x/y` 驱动标准 scale/translate/object-position，保存与离线显示不依赖内容脚本，不另存 block JSON。修改已有稿时保持两层和稳定 data-el，不把内部完整图片当成第二个设计对象。

新稿中，普通 `img[data-el]` 的可见取景优先用自身 `object-fit`、`object-position` 和圆角；需要交互裁切时由编辑器按需生成上述外框。不要再用未标记的外层容器裁切同一张独立图片，否则移动或调整图片时蒙版仍固定在原位。已有 `data-crop-frame` 是一个编辑对象，修改时保留其结构及内部图片，不另外叠加裁切层。

完成前不自动保存裁切预览；保存、源码、导出、切页/选择、结束编辑和 AI 交接安全结束会话，取消不落盘。未确认会话的草稿备份使用进入前结构。适应/填充显式重置框内取景；Fit重入后的有效操作切换覆盖模式，无操作/夹住/回起点仍保留Fit。替换仅在新图解码成功后改源并重置居中覆盖；失败保留原图。普通元素缩放、复制、图层和删除仍以外框为一个对象。

安全转换需要 CSS Typed OM 和 content-box overflow clip；picture、滤镜/mask/clip-path、不支持的变换、auto 宽度且左右拉伸的绝对布局或结构选择器引起的布局变化会拒绝转换并保留原稿。首次转换用同步可逆布局探针验证当前 marked 对象；不保证后续媒体查询或外部类规则能重新控制已迁移外框。PPTX 原生保留源图裁切、旋转和常规统一圆角，复杂 CSS 圆角沿既有导出限制明确简化，非方50%圆角使用真正ellipse。手写contain缩放/偏心、隐藏内图或破坏clip/取景关系的CSS会被PPTX明确拒绝，QA不能因此报告可靠通过；PDF保留真实DOM。

## 选择、撤销与视图

- 空白处拖动框选，相交即选中；Shift 或 Ctrl/⌘ 点击增减选择，Shift 框选追加，Ctrl/⌘ Shift 方向键按方向扩选。多选支持移动、微调、旋转、复制、删除和图层调整，批量操作可一次撤销；编辑画布时 Ctrl/⌘ A 全选当前页的逻辑对象；进入组合后只选该组内对象，不重复选择容器与后代。文字、输入框、菜单、源码、裁切和预览保留自身上下文。
- Ctrl/⌘ C 复制选中对象、Ctrl/⌘ V 粘贴到当前页，支持本页、点击缩略图切页后粘贴，以及同浏览器其他标签页；每次粘贴可撤销/重做。页面缩略图或非输入型工具按钮保持焦点时，粘贴仍作用于当前画布。未受外层裁切实际影响的对象可直接复制；只有一张图的简单圆角蒙版复制后成为可裁切的独立图片。复杂蒙版或 picture 来源会拒绝复制并清除上一次画布对象剪贴板，避免继续粘贴旧对象。目标画布若无法保持源对象的样式或几何，会拒绝并保持原稿。文字输入、源码输入和普通图片文件粘贴仍使用各自原生入口。Ctrl/⌘ D 就地复制，Ctrl/⌘ Z 撤销，Ctrl/⌘ Shift Z 重做，Delete 删除。AI「放弃」是受保护的审阅恢复，成功刷新后清空此前普通撤销历史，不能用普通重做跨越恢复。
- Ctrl/⌘ + − 0 1 或 Ctrl/⌘ 加滚轮缩放；编辑时空格加拖动平移，「适应」回到居中。
- 「播放」下拉提供连续滚动和单页全屏播放。方向键、PageUp/PageDown、空格翻页，Esc 返回预览并保留当前页；受限浏览器可能改用当前窗口播放。

「更多 → 快捷键与帮助」可持续查看当前平台键位，关闭按钮或 Esc 返回「更多」；Tab 在说明面板内移动。Mac 显示 ⌘/⇧/⌥，Ctrl 组合键仍可使用。中文输入法组词阶段不触发画布命令。键盘和菜单共用编辑权限守卫，AI 接管或只读时不能用热键改稿。

## AI 生成形状

在完整源码根目录调用 `html-design/src/shapes.js` 的 `shapeMarkup`，用参数一次生成可离线显示、可编辑的 SVG：

```js
import { shapeMarkup } from './html-design/src/shapes.js';
const svg = shapeMarkup({ id: 'p1-card-arrow', kind: 'blockArrow', width: 240, height: 72,
  fill: '#86868b', stroke: '#383838', strokeWidth: 2, radius: 12, adjust: 24 });
```

将返回的完整 `<svg>` 放在对应画板中，并保持 `data-el` 唯一。`kind` 可取 `rect`、`ellipse`、`triangle`、`diamond`、`star`、`line`、`arrow`、`blockArrow`；`strokeWidth` 范围 0–16，`radius` 和 `adjust` 范围 0–50，`width/height` 至少 8px。修改现有形状参数时，须同时更新 SVG 子节点；只改 `data-shape-*` 不会改变离线画面。编辑器的参数工具会自动同步两者。PPTX 对非矩形圆角会给出简化提示。

## 保存、审阅与导出

本地服务中停操作约0.8秒自动保存，Ctrl/⌘ S 或「更多 → 立即保存」立即保存；等顶部「已保存」再关闭。点击保存状态可重试或恢复草稿。「导出 → 下载 HTML」打包当前图片、CSS、字体及编辑器脚本，供移出目录后离线查看和普通编辑；遇到无法读取的资源会提示失败。

AI commit 后，悬停/聚焦「放弃」查看 before，点击才撤回；「接受」只更新审阅记录。多页右下可展开逐页处理或「全部接受」。人工修改并保存会接受相关范围，详见 [协作与审阅](collaboration.md)。

「更多 → 源码」查看/修改 HTML。「导出」提供 HTML、PDF 和可编辑 PPTX，后两者需 [本地运行环境](runtime.md)，导出点击时当前 DOM 的全部画板。PPTX 保留作者显式换行，普通段落随框宽重新排版；复杂 CSS 可能简化。离线仍可使用浏览器打印。
